## Plain language — why

TASK-14806 changed what "covered" means on HR's two orphan lists (the per-organisation "mangler godkender" card and the cross-organisation roll-up): an employee is now covered only when the approval walk names someone who can approve today, so a manager who has left no longer counts as cover during their five-day grace. These facts prove it from the outside, through the two real reads:

- **AC-21a-a** — the case the change exists for. A manager leaves and nobody is above them. From the day after their last day to the end of the grace, their report shows as an orphan on both lists. On today's code it shows as covered.
- **AC-21a-b** — the owner's S147 ruling Q-B = (c): a stand-in the manager appointed before leaving keeps approving, so the report stays covered.
- **AC-21a-c** — an ACTING line above still counts: the report stays covered.
- **AC-21a-d** — evidence, not a pass/fail rule. A departed manager whose team's months now go past them to the manager above. The fact records how each person is classified on both lists, and the report states which wording TASK-14806 chose for "someone's approver" (R-19). That settles, or leaves open, the one `(unproven)` NOTE the refinement carried for this item.

In all four, the card and the roll-up must say the same thing: that is the point of the one shared predicate. Expected values come from the refinement and the rulings, never from what the code returns.

~~~markdown
- **PRIMARY**: One per employee (enforced by partial unique index). The employee's designated manager.
- **ACTING**: One per employee (enforced by separate partial unique index). Temporary delegation during manager's vacation/illness. Takes precedence over PRIMARY in approval routing.

```
resolve_designated_approver(employee_id):
  1. active ACTING line → if manager is active → return manager
  2. active PRIMARY line → if manager is active → return manager
  3. if manager is inactive → recurse on manager's manager
  4. if depth > 10 OR no line exists → return NULL (fall back to org-scope)
~~~
