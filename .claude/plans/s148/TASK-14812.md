## Plain language — why

TASK-14811 corrects children's sick days to the agreement texts: they are counted **per illness** (2 days under OK24; from 1 April 2026, 3 days plus the remaining hours of the day the child fell ill, the "call-home day"), and **there is no yearly limit**. Today the year overview (Årsoversigt) shows a "Barns sygedag … saldo" tile: a yearly remaining balance. That figure no longer means anything, because nothing is used up over a year. The tile should tell the employee what they may take **for each illness** instead.

TASK-14811 changes what the server sends for that tile (the year overview's response loses the yearly remainder and gains the per-illness allowance), and REGEN has regenerated the API document on its branch. This task brings the frontend in line: regenerate the typed client, show the allowance on the tile, and keep every test green. In Skema, the new call-home code arrives as one more absence row in the catalogue the server already serves, with the server's Danish label, so the grid is expected to show it with no code change; this task confirms that and says so.
