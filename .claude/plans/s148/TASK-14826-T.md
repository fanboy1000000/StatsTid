## Plain language — why

TASK-14826 changed the Rule Engine so that it computes only with the agreement rules each request carries, refuses a request without them, refuses rules that belong to another agreement or OK version, and judges each rest by the minimum in force on the day the work ends. It also deleted the class the tests used to fetch the compiled rules (`AgreementConfigProvider`), so right now **neither test project compiles**. The next two specialists (payroll, TASK-14827; the Backend and the Orchestrator, TASK-14828) must work on a test tree that compiles, or they cannot tell their own breakage from the engine's (NR-P9). This pass does three things:

1. **Repairs the test tree**, without changing what any test proves: every test that took the compiled rules from the deleted class takes the same rules from one **shared request helper** (R-10), and every test that called a re-signed engine member hands it those rules. The values are identical, so no expected value moves.
2. **Writes the engine's own proof** (five facts, four mutations): the engine uses the rules it is handed, in the registry and through the route (AC-C1e, M-2 and M-3); each of the five routes refuses a request without rules with its fixed sentence, and `evaluate-absence` still answers without one (AC-C1i); a work end on Monday is judged by Monday's minimum rest in both directions (AC-C1j, M-4); rules that name another agreement or OK version are refused (AC-C1l, M-5); and the position-override merge carries every rule, so a department head's override can no longer silently reset the minimum rest (AC-C1p; ruling 1).
3. **Lists what stays red on purpose**: the database facts whose callers (payroll, the Backend) do not send rules yet. They turn green when TASK-14827 and 14828 land, and TASK-14828-T confirms it.

**Worked example (AC-C1j).** The helper gives AC's compiled OK24 rules; the fact sets the minimum rest to 11 h for 1–15 March 2026 and 12 h from Monday 16 March. Work: Saturday 14 March 10:00–20:30; Sunday 15 March 08:00–14:00 and 16:00–20:30; Monday 16 March 08:00–14:00. Both Sunday ends and the Monday end have 11.5 h of unbroken rest in the 24 hours before them. Expected: one finding, dated Monday 16 March; none on Sunday. Reverse the two values (12 h to Sunday, 11 h from Monday): a finding dated Sunday 15 March and none on Monday. Under M-4 (each end judged by the day before's value) both expectations fail.
