## Plain language: why

The frontend runs on React 18. React 19 has been the current major for some time, and the router move that follows (TASK-14914, react-router 8) requires React 19.2.7 or later. This task moves React and the libraries that sit directly on it:
- `react` and `react-dom`;
- their type definitions;
- the testing helpers;
- the six Radix UI primitives (dialogs, menus, selects, tabs, toasts, tooltips);
- the IBM Plex Sans font package.

It changes **no router, no Playwright and no toolchain**. TASK-14912 did the toolchain; 14914 does the router and 14915 Playwright. That way a red gate has one cause.

**Nothing the user sees may change:**
- the same 1405 vitest tests in 122 files pass, with **no expected value changed**;
- lint, the type checks and the production build stay green.
