## Plain language: why

The frontend's build tools are behind:
- Vite 5 (the build tool and dev server);
- Vitest 4 (the unit-test runner);
- ESLint 9 (the linter);
- the type definitions for Node 20.

This task moves the **toolchain only**: how the frontend is built, linted and tested, not the libraries the app runs on. React 19 is the next task, and the router is the one after it. Keeping them separate means a red gate has one cause.

**Nothing the user sees may change:**
- the same 1405 vitest tests (122 files) must pass;
- lint must still flag what it flags today;
- the production build must still succeed.
