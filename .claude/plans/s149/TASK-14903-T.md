## Plain language: why

TASK-14903 moved the production login library to IdentityModel 8.23.0. Two things remain on the test side.

1. **The Smoke tests mint their tokens with their own copy of the library** (`JsonWebTokens` 7.5.1, Smoke csproj `:14`). It moves to the same 8.23.0, so the test helper and production agree.
2. **IdentityModel 8 deliberately changed one behaviour: claim *names* are now matched case-sensitively** (`CaseSensitiveClaimsIdentity`).
   - Before, a token carrying `Role` (capital R) resolved the same as `role`. Now it does not.
   - The plan accepts this change (P-4 point 7), because nothing in StatsTid issues miscased claim names. The census in TASK-14903's written check proves it.
   - The change must still be **written down as a test of the new behaviour**, so it is visible and a later upgrade cannot silently flip it back.
   - The wave-0 security review asked for this fact to be **mandatory**. It cannot sit in the frozen wave-0 file, because there it would have gone red at this very upgrade.
