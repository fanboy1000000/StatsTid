## Plain language — why

Several Payroll test suites do not build their database from `init.sql`; they apply a hand-written copy of the `payroll_export_records` table (`PayrollExportRecordsTestSchema.cs`). If the copy does not gain the three balance columns, the payroll task's writes will fail in exactly those suites, and nobody will know whether the copy matches production. S145 built a guard for this class of drift (R51) but it does not cover this table. This pass updates the copy, extends the guard to it, and pins the new constraint.
