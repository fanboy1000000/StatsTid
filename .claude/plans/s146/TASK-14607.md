## Plain language — why

The employee's "Flex saldo" card, the year overview's flex tile and the leader's team overview all read an event, `FlexBalanceUpdated`, that nothing in the system ever writes, so they show 0 for everyone. Since TASK-14605, each paid month's export record holds its closing balance. These screens now read the employee's **latest recorded closing** and say which month it is from; an employee with no paid month sees "ingen afregnet måned" (no settled month), never a made-up 0. The owner ruled (OQ-5, 2026-10-23) that a leader's team overview keeps the flex column hidden on any row whose month the employee has not submitted (the strict reading of the S124 ruling, "a manager cannot see anything before a month is submitted"); a submitted row shows the labelled closing. The dead route, its response shape and the never-written event go.
